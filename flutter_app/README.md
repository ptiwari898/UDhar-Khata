## 🌟 Overview
Cross-platform client for **Udhar Khata**, engineered with Flutter and Dart. Features full offline-first reactivity, real-time balance aggregations, voice NLP entry, WhatsApp reminders, and customizable business profiles.

## 🚀 How to Run
```bash
# Get packages
flutter pub get

# Run on Emulator / Phone
flutter run

# Run on Web
flutter run -d chrome
```
